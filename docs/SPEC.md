# gtts 仕様

Discord のテキストチャンネルのメッセージを、ボイスチャンネルで読み上げる Go 製のボット(discordgo + disgolf)。
音声は Google 翻訳の TTS か、AITalk のデモ用 Web API(VOICEROID 系の声)で作る。
仕様を変えたときは、このファイルも必ず更新する。

## 構成

| ファイル | 役割 |
|---|---|
| `main.go` | 起動、コマンドの登録、イベントの登録、終了の待機 |
| `handlers.go` | コマンドとイベントの処理、読み上げ前の文面の整形(正規表現) |
| `manager.go`, `queue.go`, `now.go` | サーバーごとの読み上げ管理(`VoiceManager`)、読み上げの待ち行列 |
| `tts.go` | 音声の取得(Google TTS / AITalk)と ffmpeg による変換 |
| `utils.go` | 招待リンクからサーバー名を引く(`GetInvite`) |
| `vars.go`, `enums.go` | 環境変数と JSON の入出力、声の種類の表 |
| `Dockerfile`, `compose.yml` | ビルドと実行(ffmpeg 入りの alpine) |

## 設定

`.env`(または環境変数): `TOKEN`(ボットのトークン)、`OWNER_ID`(管理者のユーザー ID)、`PREFIX`(コマンドの接頭辞。例 `s!`)。
作業ディレクトリのファイル: `voice_settings.json`(ユーザー ID → `{voice_type}`)、`blocklist.json`(読み上げないユーザー ID の配列)。どちらも起動時に必須(なければ panic で終了)。compose ではホスト側のファイルをマウントする。

## コマンド(接頭辞つきのメッセージ)

| コマンド | 実行できる人 | 動作 |
|---|---|---|
| `join` | 管理者のみ | 読み上げを始める。チャンネルのメンションかリンクがあればそのボイスチャンネル、なければ実行者が今いるボイスチャンネルに参加し、このテキストチャンネルを読み上げ先にする。すでに別のボイスチャンネルにいれば移動する |
| `leave` | 管理者のみ | 読み上げを終えてボイスチャンネルから退出する |
| `voice [番号]` | 全員(ブロック中を除く) | 引数なしで声の一覧を表示。番号を渡すと、自分のメッセージを読み上げる声を設定して `voice_settings.json` に保存する |
| `bocklist`(綴りのまま) | 管理者のみ | 引数なしでブロック中のユーザーの一覧。`add <ID>`、`remove`/`delete`/`del <ID>` で追加・削除する |

自分自身とボットの発言には反応しない。

## 読み上げ

次のメッセージは読まない: 自分・ボット・コマンドの接頭辞で始まるもの・`;` で始まるもの・ほかのボットのコマンドらしい形(`BotPrefixesPattern`)・ブロック中のユーザー。
読み上げ先のテキストチャンネル以外のメッセージも読まない。本文が `s` だけなら、待ち行列を空にして再生を止める(スキップ)。

整形の順序:
1. メンションを名前に置き換える。
2. 添付ファイルの数(添付 + Discord のファイル URL)があれば「Nつの添付ファイル。」を先頭に付ける。返信なら「リプライ、」を先頭に付ける。
3. カスタム絵文字は名前だけにする。
4. 招待リンクは「招待リンク、<サーバー名>、」(取得できなければ「招待リンク、」)にする。
5. URL は「<ドメイン>のリンク」にする。`*` は消す。コードブロックは「コード省略」にする。`!!!`、`www`、`ーーー` などの繰り返しは 3 個にそろえる。
6. 100 文字未満ならそのまま、以上なら 99 バイトごとに分けて、順に待ち行列に入れる。

待ち行列(サーバーごと)は、先頭から順に音声を取得して再生する。声は話者の設定(なければ 1209)で決まる。

## 音声の取得(`tts.go`)

- 声の種類 `0`: Google 翻訳の TTS(日本語)。文字数で速さ(`atempo`)を変える(〜50: 1.2、51〜100: 1.8、101〜: 2.4)。音量は -20dB。
- それ以外: AITalk のデモ API に話者 ID、本文、速さなどを POST し、返ってきた URL から音声を取得。ffmpeg の `silencedetect` で冒頭の無音の長さを調べ、その分を飛ばして再生する。失敗は「音声合成に失敗」。
- 出力は Opus(モノラル 64kbps、`dca` で変換)。

## 招待リンクの解決

招待コードを `https://discord-invite.naecqde.workers.dev/<コード>` に問い合わせ、サーバー名を得る。429 は「discord ratelimited」、その他の失敗は「discord error」。

## ボイスチャンネルの更新

`HandleVoiceUpdates` で、ボイスチャンネルの状態の変化(退出など)を扱う。

## セキュリティ上の注意

- ボットのトークンは `.env` に置き、リポジトリに入れない。`OWNER_ID` だけが `join`、`leave`、`bocklist` を使える。
- 読み上げる文面は、利用者が書いたものをそのまま外部の TTS サービス(Google、AITalk)へ送る。
- ffmpeg にはコマンドの引数として URL を渡す(シェルは使わない)。URL は AITalk の応答から作る。
- 外部のサービスの応答は信頼しない(型の確認をしてから使う)。
